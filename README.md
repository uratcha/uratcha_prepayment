# 🥩 으랏차 선입금 관리 시스템

음식점 및 매장 전용 실시간 선입금(예약금/선불금) 통합 관리 웹 애플리케이션입니다.  
`uratcha_reservation`과 동일한 모던 디자인 시스템과 Firebase 기반 실시간 동기화 아키텍처를 공유합니다.

---

## 🚀 주요 기능

1. **실시간 데이터 동기화 (Firebase Firestore)**:
   - 포스기, 매장 태블릿, 사장님 스마트폰 등 여러 기기에서 선입금을 추가/수정/정산하면 모든 화면에 1초 내로 즉시 동기화됩니다.
   - 새 선입금 등록 시 청아한 딩동 차임음(Web Audio API) 및 시스템 푸시 알림 발송.

2. **한눈에 보는 KPI 요약 대시보드**:
   - **보관 중 선입금**: 현재 매장에서 보관 중인 잔여 선입금 총액 및 방문 대기 건수
   - **오늘 방문 예정**: 오늘 식사 예정인 고객의 선입금액 및 건수
   - **이번 달 정산 완료**: 식사 후 차감 완료된 이번 달 누적 정산액
   - **이번 달 환불 / 노쇼**: 취소 및 매장 귀속 처리된 내역 집계

3. **직관적인 상태 관리 & 퀵 액션**:
   - 🟡 **보관중 (입금완료)**: 방문 전 정상 예치 상태
   - ⚪ **입금대기**: 예약 요청 후 입금 확인 대기
   - 🟢 **정산완료**: 식사 후 총 주문금액에서 차감 정산 (현장 추가 결제액 자동 계산 모달)
   - 🔵 **환불완료**: 고객 사정 취소 시 환불 처리
   - 🔴 **노쇼**: 미방문으로 인한 선입금 매장 귀속

4. **사장님 편의 기능**:
   - **📋 원클릭 고객 안내문자 복사**: 버튼 한 번으로 방문일시, 예약인원, 선입금 확인 및 매장 안내 문구를 클립보드에 자동 생성 복사.
   - **📊 엑셀 (CSV) 다운로드**: 한글 깨짐 없는(UTF-8 BOM) 월별/전체 선입금 장부 엑셀 파일 내보내기 지원.
   - **🗑️ 안전한 휴지통 (Trash)**: 삭제 시 즉시 파기되지 않고 휴지통으로 안전하게 이동되며 원클릭 복원 및 영구 삭제 지원.
   - **다양한 필터 & 실시간 검색**: 고객명, 휴대폰 번호(끝 4자리), 메모 실시간 검색 및 방문일별/상태별 필터링.

5. **PWA (Progressive Web App) 및 모바일 최적화**:
   - 스마트폰 브라우저에서 '홈 화면에 추가'를 통해 네이티브 앱처럼 설치 및 전체화면 사용 가능.

---

## 🛠 기술 스택

- **Frontend**: Vanilla HTML5, Modern CSS3 (Pretendard Font), ES6+ JavaScript (Modular)
- **Database**: Firebase Firestore (Real-time Database)
- **Authentication**: Firebase Authentication
- **Audio & Notification**: Web Audio API (합성 차임벨), Notification API, Service Worker (PWA)

---

## ⚙️ 시작 및 배포 안내

### 1. 로컬 실행
별도의 빌드 과정 없이 `index.html` 파일을 브라우저로 열거나, 로컬 웹서버(Live Server 등)를 통해 바로 실행할 수 있습니다.

### 2. Firebase 호스팅 배포
```bash
firebase deploy
```
